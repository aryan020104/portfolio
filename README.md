# Aryan — Awwwards-Inspired World-Class Personal Portfolio

An elite, futuristic, interactive personal portfolio website for **Aryan** (Software Engineer & Full Stack Architect), designed to meet top Awwwards design standards.

![Portfolio Preview](https://images.unsplash.com/photo-1550751827-4bd374c3f58b?q=80&w=1200&auto=format&fit=crop)

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router & Server Actions)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://greensock.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) via [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/) & [@react-three/drei](https://github.com/pmndrs/drei)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Form Handling**: [React Hook Form](https://react-hook-form.com/) & [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Email Service**: Integrated EmailJS / REST handler hooks

## 🎨 Design System

- **Background**: `#050505` (Deep Black)
- **Card**: `#111111` (Rich Dark Surface)
- **Border**: `rgba(255, 255, 255, 0.08)` (Subtle Glass stroke)
- **Primary Accent**: `#3B82F6` (Electric Blue)
- **Secondary Accent**: `#8B5CF6` (Vibrant Purple)
- **Radius**: `24px` (`1.5rem`)

## 💻 Included Sections & Features

1. **Awwwards Preloader**: Animated logo, smooth percentage counter (0%-100%), progress bar, curtain wipe reveal.
2. **Interactive Custom Cursor**: Dynamic lerp cursor with follower ring, spring physics, button magnetic state, and action text labels ("VIEW", "EXPLORE", "SUBMIT").
3. **Floating Glass Navbar**: Blur background, active scroll section highlight, audio FX ambient toggle, resume download trigger.
4. **Interactive 3D Hero Section**: 
   - Left: Typewriter role cycler ("Software Engineer", "Full Stack Developer", "Problem Solver"), line-by-line reveal animation, dual CTAs, location & stack badges.
   - Right: React Three Fiber 3D Canvas with animated distorted mesh, orbiting wireframe ring, floating particles, and tech pills (Java, Spring Boot, React, Next.js, Docker, AWS, Node.js, MongoDB).
5. **About Section**: Story biography, architecture philosophy, TH Aschaffenburg academic overview, and real-time count-up stat counters.
6. **Skills Radar & Infinite Marquee**: Categorized skill cards with tilt, percentage progress rings, radial mouse glow, and dual infinite marquee ticker.
7. **Projects Showcase**: 6 featured enterprise projects with filter tabs, image zoom, architecture drawers, live demo modals, and GitHub links.
8. **Career & Education Timeline**: Vertical animated timeline with TH Aschaffenburg degree highlight card.
9. **Certificates & GitHub Activity Grid**: Interactive certificate carousel with verification badges + simulated 365-day GitHub contribution heatmap.
10. **Testimonials Slider**: Glass cards with avatars, ratings, roles, and client quotes.
11. **Contact & Confetti**: React Hook Form with validation, simulated EmailJS sending, and confetti celebration on submit.

## 🛠️ Quick Installation & Setup

```bash
# 1. Navigate to project directory
cd D:\aryan-portfolio

# 2. Install all dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build for Production

```bash
npm run build
npm run start
```
